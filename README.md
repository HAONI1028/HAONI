# HAONI

My portfolio / link-in-bio page — the link that goes in my Discord bio.

Everything on the page (name, Discord username, bio, roles, projects, links) lives in
the `PROFILE` object near the bottom of `index.html`. Edit that, push, done.

**Live Discord status (optional):** put your Discord user ID in `discordId` and join
the [Lanyard](https://github.com/Phineas/lanyard) Discord server — the page will then
show your real online status and what you're playing / listening to.
